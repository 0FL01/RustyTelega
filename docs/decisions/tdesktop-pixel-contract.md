# Telegram Desktop pixel contract (main window)

The main window copies Telegram Desktop's Night look exactly. The reference is a maximized Telegram Desktop window on a 1920×1080 KDE Plasma screen (`artifacts/telegram-donor.png`, 1919×1034, gitignored). Every value comes from the tdesktop sources (`artifacts/tdesktop`, with the `Telegram/lib_ui` submodule at c3f7343), not from measuring the picture.

## Rules

- Values live in `src/ui/td/st/` (metrics, one file per area, named after the `.style` constants) and in palette keys (`src/app_theme/keys.rs`, tdesktop's names). Components read them from there; they do not repeat numbers.
- Colours are palette keys. The default night theme is tdesktop's `night` (Quill's "Tinted"). New keys were generated by `scripts/tdesktop_parity/gen_palette.py` for Classic, Day, Tinted and Night. Quill Light and Quill Dark take the Classic and Tinted values. A theme that leaves a key out (Omarchy, older custom themes) follows the key that tdesktop's `colors.palette` defines it by (`PaletteKey::fallback`).
- Icons are tdesktop's masks (`assets/tdesktop-icons`, GPL-3.0, copied by `scripts/tdesktop_parity/sync_icons.sh`). They are drawn by `td_icon`: the grey level is the coverage, the colour is a palette key, and the 1x, 2x or 3x file is picked by scale factor.
- The interface face is Open Sans 1.10 (`assets/fonts`, the copy in `lib_ui/fonts`). Text without a size of its own is `fsize` = 13px (`Theme::text_size`). The rem stays 16px, so spacing utilities keep their size.
- What cannot match: glyph rasterisation (FreeType in Qt against GPUI's rasteriser). Text metrics (size, baseline, advance) must match; antialiasing may differ.

## Checking

```sh
WORK=$(mktemp -d)
BIN=$(scripts/tdesktop_parity/build.sh)
scripts/tdesktop_parity/capture.sh "$BIN" "$WORK/quill-full.png"   # needs kwin_wayland and spectacle
magick "$WORK/quill-full.png" -crop 1919x1034+0+0 +repage "$WORK/quill.png"
python3 -I scripts/tdesktop_parity/align.py artifacts/telegram-donor.png "$WORK/quill.png"
python3 -I scripts/tdesktop_parity/diff.py --masks artifacts/telegram-donor.png "$WORK/quill.png" "$WORK/diff"
```

The `ready-tdesktop-parity` demo reproduces the reference state: the same folders, the same four channels, and the chat with Lain. The capture runs the demo maximized in a nested, headless KWin with a 1920×1036 output (the reference's screen less its panel) and grabs the window with Spectacle, so it does not touch the desktop. The historical donor omits the last column and two bottom rows: crop the capture from the top-left as shown, without reducing the rendering viewport. Both comparison tools reject mismatched image sizes. `diff.py` prints, per region, the share of pixels that differ and writes heat maps. Avatars, the photo, the GIF and the reference's mouse pointer are masked.
