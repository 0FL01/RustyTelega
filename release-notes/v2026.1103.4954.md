### New ways to install Quill

- **Mac:** a disk image. Open `quill-macos-aarch64.dmg` and drag Quill onto the Applications folder. Apple signed and notarized both the disk image and the app.
- **Mac with Homebrew:** `brew install --cask shinycake/tap/quill-app`
- **Windows:** an installer. `quill-windows-x86_64-setup.exe` installs Quill for your account with no administrator rights, adds it to the Start menu and lists it in Settings › Apps. It isn't code-signed yet, so SmartScreen asks once: choose More info, then Run anyway.
- **Windows with Scoop:** `scoop bucket add shinycake https://github.com/shinycake/scoop-bucket`, then `scoop install shinycake/quill`
- The zips, the Linux packages and the one-line install commands work as before.

### Linux: ready for Flathub

- Quill can run as a Flatpak. Inside the sandbox it names its windows, notifications and launcher badge after the Flatpak, so your desktop groups them with the Quill icon. Settings it can't change from the sandbox, like start at login and the `tg:` link handler, show a note instead.
- The Flathub listing comes after this release.

### Not yet tested on real hardware

- The Windows installer was installed, run and uninstalled in CI, never on a real PC
- The Flatpak was built and started in Flathub's build container, never on a real Linux desktop
